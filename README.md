## 1. はじめに：『Minatowa（ミナトワ）』とは？

いつも那覇北マリーナからの安全な運航とガイド業務、お疲れ様です。

『Minatowa（ミナトワ）』は、**「港の仲間ショップ同士でボートの空席やガイドを助け合い、直前のトラブルを防ぎ、月末の面倒な振込作業をゼロにする」** ために開発された、沖縄ダイビング専用の寄り合い協調システムです。

- **ボートを持っているショップ様**: 「明日のボートに空席がある」「急に体験ダイビングが増えて自社ガイドだけでは足りない」ときに、仲間からゲストを受け入れたり応援ガイドを呼ぶことができます。
- **ボートを持っていないショップ様**: 「繁忙期の連休にボート席を確実に先回りキープしたい」「予約が入った日の送迎や器材の段取りをスムーズにしたい」悩みを解決します。
- **個人フリーランスのガイド様**: スマホひとつで明日の集合場所・船名・日当を確認でき、空き日には港のショップから安心してオファーを受託できます。

現在、パラダイス倶楽部様にご確認いただける**試作品（サンプル画面・全11画面）**をご用意しました。
パソコンやタブレット、スマートフォンのブラウザで実際にボタンを押しながら、現場の使い勝手をご確認いただけます。

## 3. あなたの立場に合わせた「おすすめ見学コース」

ショップの営業形態に合わせて、まずは以下の画面からご覧いただくのがおすすめです。

### コースA：自社ボートをお持ちのオーナー様・船長様
毎朝の出航前の段取りと、自社船の稼働率アップを体感してください。
1. **【画面1-A】運航デッキ・乗船チーム編成ボード**
   - 朝の出港前や夕方の段取り画面です。どのボートにどのショップのゲストが乗り、誰が引率するかを直感的に組むことができます。
2. **【画面5】ボート運航ダイヤ＆段階的開放設定**
   - 「30日前は自社予約用にキープ」「14日前になったら港の仲間に先行公開」「直前は全開放」など、空席を段階的に自動で埋める設定ができます。
3. **【画面2】港内シェア要請・公募ボード**
   - ボートの残席を埋めたいときや、急病・エンジントラブル時に他社ボートへ助けを求めるときの画面です。

### コースB：自社ボートを持たずに乗り合いを利用するショップ様
数ヶ月前の先回りキープから、日々の送迎・器材準備までを1画面で完結できます。
1. **【画面1-B】月間配船＆ゲスト手配ダッシュボード**
   - カレンダーで「自社の予約人数」と「確保したボート席」が一目でわかります。席が足りない日は赤字で警告され、ボタン1つで港の仲間に空席を相談できます。
2. **【画面4】予約カルテ・参加者書類提出台帳**
   - 予約ごとのゲスト全員のメディカルチェック（問診回答や医師の診断書）が揃っているかを一覧で管理できます。

### コースC：フリーランスのガイド・インストラクター様
毎日のスマホ片手での現場確認と、オファーの受託画面です。
1. **【画面1-C】マイスケジュール＆オファー受付ボード**
   - 「明日の現場（集合7:45、パラダイス号、日当15,000円）」が大きく表示され、集合場所の地図確認や船長への連絡もワンタップです。
   - ショップからの応援依頼を「受ける／見送る」も指一本で選べます。

## 4. ぜひ触って試してほしい！「5つの便利機能」

画面を開いたら、ぜひ以下のボタンや機能を実際にクリックしてみてください。

### ① 【安全比率の自動チェック】（画面1-Aで体験）
- 体験ダイビングは「ガイド1人につきゲスト2人まで」、ファンダイビングは「ガイド1人につき4人まで」といった海の安全ルールが組み込まれています。
- 人数をオーバーするチームを作ると、画面に**赤い警告**が出て「出航前アラート」が知らせてくれます。

### ② 【海上保安庁の乗船名簿が一発で出る】（画面1-Aで体験）
- 画面右上の **「🖨️ 海保・港湾提出名簿を出力」** ボタンを押してみてください。
- 自社ゲストと他社から預かったゲストが全員まとまり、住所・生年月日・緊急連絡先・当日の船長名が綺麗に整列した提出用名簿（印刷用・CSV）が即座に作成されます。手書きで書き写す手間がなくなります。

### ③ 【お客さんがスマホで問診・サインを済ませてくる】（画面9で体験）
- **画面9** は、お客さんが海に来る前の日や自宅で開くスマホ画面です。
- 最新のダイバーメディカル（WRSTC様式）に沿っており、もし喘息や心臓疾患で「はい」を選んだ場合のみ、**「医師の診断書写真アップロード」** 枠が自動で開きます。
- 画面上で指で手書きサインをして完了すると、当日の集合場所（Googleマップ）とQRコード付きのデジタル搭乗券が表示されます。紙の書類を船上で書かせるバタバタがなくなります。

### ④ 【「言った・言わない」を防ぐ前日18:00の合意ロック】（画面3で体験）
- 前日夕方の締め切り（18:00）を過ぎた後の急な減員やキャンセルについて、双方のショップで合意を取る画面です。
- 「海況が悪くて出航中止（台風など）」のときはキャンセル料0円、「お客さんの自己都合」のときは港のルールに従ったキャンセル料を自動計算し、二者間で電子承認ログを残します。

### ⑤ 【月末の現金のやり取りがゼロになる「自動相殺」】（画面7で体験）
- A店から受け取ったボート代と、A店に支払うガイド料などを、システムが自動で差し引き（相殺）します。
- **「差額だけを1回振り込めばOK」** になるため、月末に何件も振込手数料を払って往復送金する必要がなくなります。
- また、キャンセル違約金は法律（国税庁通達5-2-5）に則り「消費税がつかない不課税」として正しく自動仕分けされます。

## 5. 【設計のウラ話】Minatowaが現場で本当に役立つ「7つのこだわり」
〜 データベース設計書・UI設計書から読み解く、現場専用の安心設計 〜

Minatowaは、一般的な予約ソフトや業務システムとは根本的に作りが異なります。
海の現場の過酷さや、ショップ同士の貸し借り・安全管理の難しさを徹底的に研究して設計されています。ここでは、システムの裏側に込められた**「7つのこだわり」**をわかりやすくご紹介します。

### ① 「会社単位」ではなく「同じ港（那覇北マリーナ）」を軸に繋がる
- **なぜ？**: ダイビングで一番の制約は「どの港から船が出るか」です。港が違えば集合場所も時間も送迎ルートも合わず、現場が破綻します。
- **Minatowaの工夫**: 会社単位ではなく、**「那覇北マリーナを母港とするボート」と「その港を利用するショップ・ガイド」** を基本単位として繋ぎます。これにより、毎朝の集合やゲストの合流が最もスムーズな仲間同士で助け合うことができます。

### ② 「代表者3名」ではなく「生身のゲスト1人ひとり」の安全カルテを完全管理
- **なぜ？**: 「山田様・他2名」で予約が入っても、海で潜るのは1人ひとりの生身の人間です。Cカードのランク、経験本数、病歴、器材サイズは全員バラバラです。
- **Minatowaの工夫**: 予約番号だけでなく、**参加者1人ひとりの安全カルテ（病歴・Cカード・器材）を独立して管理**しています。他社にボート席やガイドをお願いするときも、ゲスト個人の健康・安全データが漏れなく相手に引き渡されるため、現場での確認ミスや万一の事故を未然に防ぎます。

### ③ 「ファンと体験が混ざった友達グループ」の部分委託ができる
- **なぜ？**: 「友達3人組で予約が入ったが、2人はファンダイビング、1人だけ体験ダイビング。自社の船に全員乗せるが、体験ダイブの子だけ他社のガイドに預けたい」といった現場あるあるが日常茶飯事です。
- **Minatowaの工夫**: グループ全員を丸投げするだけでなく、**「この1人だけ他社にお願いする」という柔軟な部分委託**が可能です。さらに、船の「席数定員」だけでなく、**「ガイド1人が安全に引率できる人数（体験1:2、ファン初級1:4など）」** をシステムが自動計算し、危険な人数のチーム編成を出航前に画面上でピピッと警告ブロックします。

### ④ 自社スタッフは「他社から勝手に取られない」保護 ＆ フリーランスは「空き日を能動登録」
- **なぜ？**: 自社の社員インストラクターを勝手に他社から指名されては困ります。一方、個人フリーランスのガイドは「早く仕事の予定を埋めたい」と考えています。
- **Minatowaの工夫**: 
  - ショップの自社スタッフは**「外部非公開」で鉄壁ガード**されています。自社の予約が少なくて手が余った日だけ、ショップが許可して外へ応援派遣できます。
  - フリーランスのガイド様は、スマホから「○月○日、那覇北マリーナで働けます」と**空きシフトを自由に事前エントリー**できます。夕方の締め切り時にガイドが足りない船から自動でオファーが届く仕組みです。

### ⑤ 「言った・言わない」の金銭トラブルを防ぐ、前日18:00の電子合意ロック
- **なぜ？**: 現場で最も揉めやすいのが「前日夕方の急なキャンセルや減員」です。電話やLINEだと「言った」「聞いてない」のトラブルになりがちです。
- **Minatowaの工夫**: 那覇北マリーナで決めた共通ルール（例: 前日午前は無料、18:00以降は規定料金など）に基づき、**システムが自動でキャンセル料を計算し、双方の画面上で合意ログを電子的にロック**します。もちろん、台風などの海況悪化（船止め）の場合は自動でキャンセル料0円として処理されます。

### ⑥ 月末の現金の振り込みがゼロになる「自動相殺」と「正しいインボイス」
- **なぜ？**: 「A店にボート代を10万円振り込み、同じA店からガイド料7万円を振り込んでもらう」といった往復送金は、手数料も手間も無駄です。
- **Minatowaの工夫**: 月末になると、港の仲間同士の貸し借りを自動で差し引き（相殺）し、**「差額の3万円だけを1回振り込めば精算完了」** という精算明細書を発行します。さらに、キャンセル違約金は法律（消費税法）で「消費税がかからない不課税」と決められていますが、これも**税理士さんがそのまま使えるインボイス形式で正しく自動仕分け**されます。

### ⑦ 紙カルテの老舗店も安心な「自社保証ボタン」＆ 船の上でも迷わない「現場特化UI」
- **なぜ？**: 「うちは昔から紙カルテやエクセルでしっかり顧客管理しているから、いまさら全員にスマホで問診を打たせるのは難しい」「船の上は直射日光で画面が見づらく、手も濡れている」という声があります。
- **Minatowaの工夫**: 
  - **ハイブリッド運用**: 「うちの店が責任を持って確認済みです」という**自社保証ボタン**をワンクリックするだけで、従来の紙カルテ運用のままでもスムーズに船に乗せられます。
  - **1画面1ミッション設計**: 1つの画面にあれもこれも詰め込まず、「出港前はこの画面」「予約の配船はこの画面」「経理は事務所でこの画面」と目的ごとに分けることで、揺れる船の上やスマホ片手でも誤操作が起きない工夫を凝らしています。

## 6. 港のルール（ガバナンス）について

『Minatowa』は、システムが勝手にルールを押し付けるものではありません。
**【画面8】港・寄り合いガバナンス設定** で、那覇北マリーナのショップの皆様が話し合って決めたルールを自由に変更・調整できます。

- 前日の公募締め切り時刻（例：昼12:00締切、夕方18:00運航確定）
- ガイドの安全引率比率（例：体験1:2、ファン1:4）
- 港内での標準的な相殺手数料率
- 新しいショップが寄り合いに参加したいときの承認手続き
